## Remaining limits and rollback

The full bank has not been semantically certified. The 33-question audit and candidate corrections are documented separately. Visual testing covered the local mobile source/report journey; full assisted-exam and admin-edit visual journeys inside Telegram remain unverified, although their API behavior is tested.

A Worker rollback can retain the additive migration. Do not drop report or revision tables. Reverting to old code would restore unchecked-cache behavior, so prefer a forward fix for content issues. The pre-release SQL export is a recovery artifact, not a routine rollback script: restoring it would discard subsequent user activity.
